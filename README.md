# signal_bot

Telegram-бот для продажи подписки на торговые сигналы с оплатой в USDT.

## Что уже есть

- `/start`: приветствие, дисклеймер и выбор тарифа.
- Выставление счёта с уникальной суммой (30.01, 30.02, ...) на один адрес приёма. По сумме бот потом узнаёт, чей пришёл платёж.
- Отмена счёта, истечение счёта по времени, `/status` с датой окончания подписки.
- `/stats` для админов.
- Модели данных: пользователи, тарифы, счета, платежи, подписки, сигналы, журнал действий.

Ещё не сделано: мониторинг блокчейна, активация подписки после оплаты, доступ в канал, публикация сигналов.

## Запуск

```bash
cp .env.example .env   # заполнить BOT_TOKEN, ADMIN_IDS, PAYMENT_ADDRESS
docker compose up -d --build
```

Тарифы создаются при первом запуске с ценами-заглушками, их можно поменять в таблице `plans`.

## Тесты

```bash
pip install -r requirements-dev.txt
pytest
```
