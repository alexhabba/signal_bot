# signal_bot

Telegram-бот для продажи подписки на торговые сигналы с оплатой в USDT.

## Что уже есть

- `/start`: приветствие, дисклеймер и выбор тарифа.
- Счёт с уникальной суммой (30.01, 30.02, ...) на один адрес приёма USDT TRC-20.
- Мониторинг оплаты через TronGrid: раз в 30 секунд бот забирает подтверждённые входящие переводы настоящего USDT и сопоставляет их со счетами.
  - Точная сумма: подписка активируется (или продлевается от текущей даты окончания), пользователь получает сообщение, что полные сигналы будут приходить в этот чат.
  - Недоплата с теми же копейками (биржа вычла комиссию): пользователь и админ получают уведомление, админ закрывает вручную через `/grant`.
  - Перевод, который не подошёл ни к одному счёту: уведомление админу.
  - Поздняя оплата истёкшего счёта засчитывается: сумма держится за ним 24 часа.
  - Один и тот же перевод не засчитывается дважды.
- Сигналы: админ пишет `/signal <текст>`, бот рассылает его в личку всем с активной подпиской (с запретом пересылки). Бесплатные сигналы: `/free <текст>` публикует в открытый канал.
- Необязательный приватный канал (`CHANNEL_ID`): доступ по заявке, бот одобряет её только при активной подписке.
- Планировщик: истечение неоплаченных счетов, напоминания за 3 дня и за 1 день, удаление из канала после окончания подписки.
- Команды пользователя: `/status`, `/link` (новая ссылка в канал).
- Команды админа: `/stats`, `/grant <user_id> <дней>`, `/unmatched` (спорные платежи).

Автоматический источник сигналов (скрипт, TradingView) пока не подключён: сигналы публикуются вручную.

## Настройка каналов

Открытый канал (необязательно, для бесплатных сигналов): создайте его, добавьте бота админом с правом публикации, id укажите в `PUBLIC_CHANNEL_ID`.

Приватный канал (необязательно, обычно не нужен):

1. Создайте приватный канал и добавьте бота админом с правами «Пригласительные ссылки» и «Блокировка пользователей».
2. Узнайте id канала (например, переслав сообщение из канала боту @userinfobot) и укажите его в `CHANNEL_ID`.
3. В настройках канала включите «Запрет копирования», чтобы сигналы нельзя было переслать.

## Запуск

```bash
cp .env.example .env   # заполнить BOT_TOKEN, ADMIN_IDS, PAYMENT_ADDRESS
docker compose up -d --build
```

Тарифы создаются при первом запуске с ценами-заглушками, их можно поменять в таблице `plans`.

## Тесты

```bash
pip install -r requirements-dev.txt
pytest
```
